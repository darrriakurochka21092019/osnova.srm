# Дальнейшая проверка и развитие

1. Пилот с двумя устройствами из российских сетей, документами ОГЭ/ЕГЭ и 60–90-минутным уроком; затем мини-группа до четырёх участников.
2. Проверка Docker на выбранном VPS: HTTPS, резервирование, восстановление и контроль свободного места.
3. Отдельное обследование существующей CRM. Единое владение учениками/расписанием, mapping UUID и авторизация; без автоматического слияния по имени/почте.
4. Уточнение массовых сценариев: пагинация, фильтрация на сервере, пагинация истории уроков, фоновые задания импорта PDF, уборка неиспользуемых файлов по проверенным ссылкам.
5. Продвинутые рабочие листы, морфемные шаблоны, интерактивные тренажёры с безопасным хостингом, экспорт всей доски одним PDF.
6. Подключение дополнительных каналов уведомлений при наличии согласий и каналов доставки.
7. Видеосвязь как отдельный модуль после выбора и испытаний провайдера. В этой версии её нет.
