# План проверки

Автоматические API-тесты используют независимую временную базу. При OSNOVA_TEST_DATABASE_URL выполняется тот же набор на отдельной PostgreSQL с именем osnova_test; локально используется PGlite.

| Сценарий                 | Проверка                                                                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| Первоначальная настройка | Только один преподаватель, нет повторного bootstrap                                                                               |
| Авторизация              | Сессия обязательна, пароль не возвращается, чужой Origin отклоняется                                                              |
| Изоляция учеников        | Чужой board_id/page_id/file_id не открывается                                                                                     |
| Разные объекты           | Независимые изменения двух участников объединяются                                                                                |
| Один объект              | Устаревшая базовая версия возвращает явный конфликт                                                                               |
| Повтор запроса           | Один operationId не создаёт повторных действий                                                                                    |
| Удаление                 | Tombstone не превращается в живой объект при устаревшем повторе                                                                   |
| История                  | Восстановление с expectedRevision; текущая версия не теряется                                                                     |
| Приглашения              | Лимит входов, отзыв, снятие членства, блокировка архива                                                                           |
| Загрузки                 | Сигнатура/MIME, приватность, PDF 31 страница отклоняется                                                                          |
| Домашняя работа          | Назначение, ответ, проверка и защита баллов от изменения учеником                                                                 |
| Напоминания              | Один dedupeKey не создаёт повторные записи                                                                                        |
| Перезапуск               | Постоянная база открывается со старой доской и сессией                                                                            |
| Backup/restore           | Контрольные суммы и восстановление в новую папку                                                                                  |
| Единый холст             | Идемпотентное объединение прежних сцен; исходные дополнительные сцены сохранены; запись в них после объединения запрещена         |
| Фон доски                | Сохранение одного из четырёх фонов; редактор меняет, зритель не меняет                                                            |
| Модель презентации       | Преобразование прежних PDF-страниц, отдельные пометки слайдов, скрытие без удаления, перенос/масштабирование пометок вместе с PDF |

Браузерный сценарий использует настоящие Chromium и сервер со статической production-сборкой. Независимые контексты учителя, гостя и ученика: совместный текст, экспорт полученных удалённых правок, отключение сети и reload, локальная undo/redo без удаления чужого объекта. На доске проверяются четыре синхронизируемых фона, импорт двухслайдового PDF как одного перемещаемого объекта без создания новых страниц, рисование, принадлежность пометок слайду, перемещение PDF вместе с пометками, переключение слайдов и reload в другом сеансе, PDF-экспорт. На ширине 390 px дополнительно проверяются переключение слайдов и границы панели выбора фона. Остальной сценарий: активация кабинета, черновик и отправка работы, проверка, баланс 500 ₽ при одном проведённом и одном отменённом уроке. Проверяется отсутствие горизонтального переполнения всех основных маршрутов при 1440 и 390 px.

Проверки на реальном сервере выполняются отдельно: Docker/PostgreSQL/HTTPS, права файловых volumes, доступ из российских сетей, Firefox/Edge/Safari и iOS, четыре участника, 30-страничные сканы, 90 минут занятия, восстановление PostgreSQL + uploads. Короткий локальный тест не заменяет эти испытания.

Регрессия пера использует CDP `Input.dispatchMouseEvent` с `pointerType=pen` и переменным `force`: над PDF уже есть 600 пометок на другом слайде. Проверяются непрерывная линия с паузой дольше задержки автосохранения, реальные значения нажима в сохранённом объекте и 12 быстрых контактов без пропущенных штрихов. Счётчик `IDBObjectStore.put` требует ноль записей сцены при прижатом пере, ноль бинарных данных внутри контрольных точек и отсутствие повторного сохранения изображений между штрихами. Отдельно прерывается отправка операции, затем выполняются reload, восстановление 14 штрихов и изображений слайдов и повторная отправка. Новый браузерный контекст получает локальный черновик прежней версии IndexedDB; после открытия доски проверяется его восстановление на сервер и переход на версию 2. Физические планшеты/драйверы Windows Ink проверяются дополнительно на устройстве пользователя.

## Уроки с постоянными комнатами

`tests/classrooms.test.ts` проверяет автоматическую комнату, повторное использование доски/ссылки, изоляцию учеников, ожидание без преподавателя, единственное активное занятие, идемпотентное завершение и контрольные версии. Дополнительно: комментарии с повтором UUID, права edit/view, отзыв ссылки и гостевой сессии, личные входы в одну мини-группу, скрытая приватная заметка, назначение задания один раз каждому участнику, блокировка паузы, отсутствие доступа к прежней личной доске после изменения состава, неизменность сцены/фона прошлых материалов. PostgreSQL-версия этого набора использует отдельную случайную schema внутри osnova_test и удаляет её после завершения.

`tests/e2e/lessons.spec.ts` проверяет пользовательский путь через production-интерфейс: создание ученика, подготовка с PDF, собственные панели рисования/undo/redo, вход по постоянной ссылке на 1440/390 px, ожидание и автоматический переход после начала, реальные комментарии/рука, права, завершение у обоих участников, итоги и назначение задания, приватность заметки, просмотр прошлой презентации без изменения общей доски, следующий урок по прежней ссылке, недействительная ссылка. Заглушки не вызывают getUserMedia. Отдельный сценарий подключает преподавателя и трёх учеников по их личным ссылкам в одну мини-группу, проверяет персональные права, просмотр истории без изменения сцены и отсутствие перекрытия нижних панелей на планшете.
