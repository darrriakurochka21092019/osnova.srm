# Принятые решения

1. **Excalidraw 0.18.1.** Готовые доступные инструменты, кириллица, фигуры, выделение, undo/redo и переносимая сцена. Совместный сервер реализован отдельно.
2. **Элементные операции с проверкой базовой версии.** Простая воспроизводимая политика конфликтов, без перезаписи сцены и обещания одновременного набора одного текста.
3. **PGlite для локального запуска, PostgreSQL для сервера.** Пользователю Windows не нужна отдельная СУБД. На VPS остаются полноценные транзакции PostgreSQL. Миграция между режимами — отдельная будущая процедура.
4. **PDF.js legacy build.** Дополнительные полифиллы нужны браузерам, в которых ещё нет новых методов Map. Модуль worker и все дополнительные ресурсы поставляются приложением.
5. **Cookie-сессии.** Непрозрачный случайный токен, в БД — только SHA-256. HttpOnly, SameSite=Strict, Secure на сервере. Пароли — scrypt с солью. Публичной регистрации нет.
6. **Встроенные уведомления.** Без зависимости от зарубежных каналов. Планировщик повторно проверяет необработанные события; уникальный dedupeKey исключает дубли. Тихие часы и отключение напоминаний относятся к напоминаниям об уроках; учебные события сохраняются.
7. **Учёт по факту урока.** Отменённый/будущий урок не начисляет долг. Цена мини-группы задаётся за одного участника.
8. **Без копирования исходников существующей CRM.** Репозиторий был пуст. Неизвестная база кабинета не подменяется вымышленной интеграцией.

9. **Урок с постоянной комнатой.** Ученик автоматически получает комнату и каноническую доску; отдельные приглашения к каждой доске исключены из ежедневного сценария. Одни личные ссылки работают для индивидуальных занятий и мини-групп. Старые материалы не удаляются.
10. **Явный жизненный цикл.** Подготовка не равна началу урока. Только владелец начинает/завершает занятие; версии начала/конца и общие итоги относятся к session, доска остаётся постоянной. Приватная заметка преподавателя не входит в публичную проекцию session.
11. **Видеосвязь как обозначенная заглушка.** Макеты входа и рабочей комнаты сохранены, но элементы камеры/микрофона/экрана отключены. Разрешения устройств не запрашиваются, присутствие и комментарии работают независимо.

- **Форматированный текст через сохраняемый источник и приватный рендер.** Native Excalidraw 0.18.1 не предоставляет bold/italic/underline и произвольный набор шрифтов в публичном API. Вместо изменения движка используем TextModel + PNG image и свой inline-редактор. Одинаковый вид для участников/экспорта, обычные native трансформации и права доступа; ограничение — сторонний Excalidraw редактирует такой блок как картинку. Старые native text совместимы.
- **Один холст, параметры печати отдельно.** В новом окне скачивания нет управления страницами доски; область вписывается в один A4/A3 либо сохраняет размер холста. Импорт остаётся одной кнопкой панели, без дополнительного модального загрузчика.

- **Одна панель свойств и перенос отдельно от изменения формы.** Клик открывает общий компактный инспектор, перенос тела меняет только позицию; редактирование размеров остаётся за native-маркерами. Текст вводится сразу на холсте без всплывающей панели, замок остаётся отдельной кнопкой. Галерея не содержит подписей стикеров и трёх удалённых морфемных знаков, сохранённые сцены совместимы.

- **Общая оболочка кабинета поверх прежних данных.** Новый стиль и паттерн используются всеми страницами преподавателя; формы и превью вынесены в модули cabinet. Не создаём второй набор учебных данных. Программа остаётся текстом, доработка работы использует assigned/feedback, дополнительные части отчёта — совместимые поля JSON. В макетах показываем только работающие возможности; видеосвязь и внешние каналы остаются явно неподключёнными.
