# Основа · учебное пространство

Адаптивная платформа репетитора по любому предмету: совместная доска, кабинеты, расписание и учебные процессы. Версия 0.1, без видеосвязи.

## Возможности

- Общая доска с несколькими участниками, курсорами, ручкой, маркером, ластиком, текстом, фигурами, линиями и стрелками. Выделение, перемещение, масштаб, отмена и повтор.
- Один бесконечный холст с текстами, изображениями и PDF-презентациями. Слайды переключаются внутри презентации, пометки сохраняются для каждого слайда. Исходные файлы, автоматическое сохранение и последние 50 версий холста.
- Общие инструменты для любого предмета, перемещение и изменение размера презентаций, четыре фона: белый, клетка, линии, точки. Экспорт холста с фоном в PNG/PDF и редактируемая сцена со всеми слайдами.
- Приглашения на просмотр/редактирование со сроком и лимитом входов, отзыв ссылок и доступов. Учитель, ученик и временный гость.
- Карточки учеников, цели, программы, расписание дня/недели/месяца, мини-группы, статусы уроков и запрос переноса.
- Домашняя работа: материалы, сроки, черновик, текст и фотографии ответа, отправка, проверка, баллы и обратная связь.
- Библиотека с папками и выборочной публикацией, диагностика, прогресс, отчёты с автозаполнением и печатью в PDF.
- Оплаты, расходы, авансы и задолженности по проведённым урокам, CSV для Excel. Отменённые уроки не создают начисления.
- Несколько файлов документа, задачи, заметки, встроенные уведомления, напоминания с тихими часами, профиль и управление сеансами.
- Адаптация интерфейса для телефона, нижняя навигация, знакомство с платформой и справка.

В репозитории нет настоящих данных учеников, паролей и готовых учётных записей.

## Быстрый запуск на Windows

Понадобятся **Node.js 24 LTS** и **Git**. Команды выполняются в PowerShell.

```powershell
git clone https://github.com/darrriakurochka21092019/osnova.srm.git
cd osnova.srm
npm ci
Copy-Item .env.example .env
npm run dev
```

Откройте **http://localhost:5173**. При первом запуске создайте свой аккаунт преподавателя. Затем добавьте ученика и создайте доску. Приглашение в кабинет ученика создаётся из его карточки; разовое приглашение на доску — внутри доски.

Данные хранятся на диске в `data/`: локальная PostgreSQL-совместимая база PGlite и исходные файлы. Остановка приложения не стирает занятия. Не удаляйте эту папку и не запускайте две копии API с одной папкой данных.

Если PowerShell запрещает запуск `npm.ps1`, используйте `npm.cmd` вместо `npm`.

### Запуск собранной версии

```powershell
npm run build
$env:APP_ORIGIN = "http://localhost:3001"
npm start
```

Откройте **http://localhost:3001**. Чтобы приглашения работали на другом компьютере через интернет, нужен сервер с HTTPS и правильный `APP_ORIGIN`. GitHub хранит исходный код; GitHub Pages не запускает этот сервер и совместную доску.

## Проверка

```powershell
npm run check
npx playwright install chromium
npm run test:e2e
```

`check` проверяет TypeScript, собирает приложение и выполняет API-тесты. Браузерный тест запускает изолированный сервер с временной базой, проверяет совместную доску в независимых сеансах, разрыв сети, PDF, домашнюю работу, расчёт долга и страницы при ширинах 1440 и 390 px. Пользовательская база при тестировании не используется.

## Развёртывание и резервные копии

На сервере используется Docker Compose: приложение, PostgreSQL и Caddy с HTTPS. Нужен домен, направленный на сервер; публичными остаются только порты 80 и 443. Подробные команды, обновление, резервирование и восстановление: [инструкция эксплуатации](docs/06_OPERATIONS.md).

## Устройство проекта

```text
apps/api/src/           Fastify, авторизация, права, HTTP и Socket.IO
apps/web/src/           React, кабинеты, учебные процессы, доска
packages/contracts/    общие типы и Zod-схемы
scripts/               подготовка локальных ресурсов, backup/restore, тестовый сервер
tests/                 API и браузерные сценарии
deploy/                конфигурация HTTPS
docs/                  состояние, архитектура, API и регламент проверки
```

Все шрифты и ресурсы PDF обслуживаются своим приложением. Обязательных платных API и CDN в работе нет. Для локального старта не требуется установка PostgreSQL; в Docker используется обычная PostgreSQL через тот же SQL-адаптер.

## Границы этой версии

- Видеозвонки, email, Telegram и Web Push не подключены. Уведомления приходят внутри платформы; планировщик работает при запущенном API.
- Существующий личный кабинет/CRM не изменялся и не импортировался: его исходники не предоставлены. В этой версии собственные UUID и API; интеграция потребует проверки действующей модели данных.
- PDF: до 25 МБ и 30 страниц без пароля; PNG/JPEG/WebP до 25 МБ и 40 мегапикселей. Другие офисные форматы сначала экспортируются в PDF. Фон PDF растровый (1.75×), исходник сохраняется отдельно.
- Совместная работа идёт по объектам. Одновременная правка одного объекта вызывает явный конфликт: подтверждённая сервером версия остаётся, локальный вариант можно скачать. Это не побуквенный редактор одного текста.
- Локальная очередь доски помогает пережить разрыв связи; новое открытие всей платформы без сети и офлайн-изменение остальных разделов не предусмотрены. Перед очисткой данных браузера дождитесь статуса «Сохранено».
- Интерфейс показывает до 5000 записей одного вида. Для большой школы потребуются пагинация, дополнительный аудит и нагрузочные испытания. Длительные уроки из российских сетей и реальный Docker/VPS проверяются на пилоте.
- PNG/PDF-экспорт включает общий холст и текущий слайд каждой презентации. Отчёты экспортируются через диалог печати браузера. Финансы выгружаются в CSV, который открывается в Excel.
