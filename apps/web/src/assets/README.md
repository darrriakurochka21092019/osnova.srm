# Изображения EduSpace

Изображения предоставлены владельцем проекта для интерфейса платформы.

- `eduspace-logo.png`, `eduspace-mark.png` — основной логотип и иконка книги.
- `eduspace-white.webp` — светлый логотип из файла «лого белый.png» для фиолетового блока входа.
- `login-ed.webp` — «Эд учится среди раскрытых страниц(1).png».
- `lesson-banner.webp` — «Фиолетовый баннер с объёмной книгой(2).png».
- `page-pattern.webp` — «Нежный узор раскрытых страниц(1).png», общий фон кабинета и входа в урок. Размер 1672×941; сравнение всех пикселей с оригиналом: 0 отличий.

WebP подготовлены без потери качества. Иллюстрации сохраняют исходные пиксели; у светлого логотипа сохранены прозрачность и все видимые пиксели. Изображения и шрифты загружаются локально, без внешнего сервиса. Размер и кадрирование задаются только компонентом `Brand` и стилями страницы.
